# TOKIYO STORE Launch Runbook

## 1. Infrastructure
- Deploy Supabase schema.
- Configure production environment variables.
- Verify domain and HTTPS.
- Create/verify Super Admin.

## 2. Merchant sandbox
- Successful payment.
- Failed payment.
- Timeout.
- Duplicate webhook.
- Refund.

## 3. Top-Up sandbox
- Successful fulfillment.
- Pending fulfillment.
- Provider failure.
- Retry.
- Fallback provider.
- Duplicate fulfillment protection.

## 4. Provider controls
- Balance sync.
- Low balance auto-disable.
- Health auto-disable.
- Recovery auto-enable.
- Failover rerouting.

## 5. Storefront
- Mobile + desktop.
- Physical accessory checkout.
- Digital top-up checkout.
- Order history/tracking.
- SEO sitemap/robots.

## 6. Launch
Only switch live credentials on after every required Launch Checklist item is complete.
