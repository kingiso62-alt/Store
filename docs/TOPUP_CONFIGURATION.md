# TOKIYO Top-Up Configuration

1. Create digital product in Products.
2. Create a Top-Up API Provider in API Providers.
3. Open Top-Up Packages.
4. Map:
   - digital product
   - provider
   - provider product code
   - package label
   - provider cost
   - customer selling price
5. Add multiple providers for the same customer product when fallback/routing is desired.

Provider selection can use cost, availability and priority.
