# TOKIYO STORE V33 — After-Sales, Inventory Ledger & Daily Sales

TOKIYO STORE now adds:
- Gaming accessory return requests
- Admin after-sales return workflow
- Customer return notifications
- Stock movement ledger
- Restock / adjustment / damage / return stock entries
- Daily sales summary for the last 30 days

Digital top-ups remain separate from physical accessory returns. This keeps API fulfillment and warehouse/after-sales operations clearly separated.
